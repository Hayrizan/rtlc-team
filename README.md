# RTLC TEAM Website

Официальный статический сайт-визитка **RTLC TEAM — Russian Translate Localisation Crew**. Сайт рассказывает о команде, показывает актуальный каталог русификаторов и ведёт на официальные публикации RTLC в Boosty.

Сайт написан на HTML, CSS и Vanilla JavaScript, не требует сборщика и готов к размещению на GitHub Pages.

Опубликованная версия: <https://hayrizan.github.io/rtlc-team/>

## Local development

Самый простой вариант — запустить локальный HTTP-сервер из корня проекта:

```bash
python -m http.server 8080
```

После этого откройте `http://localhost:8080`. Также сайт можно открыть напрямую через `index.html`, но HTTP-сервер точнее воспроизводит поведение GitHub Pages.


## Adding a localization

Новый проект добавляется одной записью в массив `window.RTLC_PROJECTS` внутри [`js/projects.js`](js/projects.js):

```js
{
  id: "game-slug",
  steamAppId: 123456,
  name: "Game Name",
  type: "translation", // translation или voice
  access: ["free"],    // free, exclusive или оба значения
  tags: ["Текст", "Текстуры"],
  boosty: "https://boosty.to/rtlc/posts/...",
  steam: "https://store.steampowered.com/app/.../", // необязательно
  description: "Короткое подтверждённое описание."   // необязательно
}
```

Дополнительные необязательные поля карточки: `updatedAt` (дата обновления
перевода, `YYYY-MM-DD`), `translationVersion` (версия перевода), `gameVersion`
(подтверждённая совместимость с игрой), `supportStatus` (статус поддержки),
`accessDetails` (различия бесплатной и эксклюзивной версий), `checkedAt`
(дата проверки сведений). Источник — публикация проекта по ссылке `boosty`.
Не подменяйте дату обновления перевода датой проверки; неизвестные сведения
показываются как неуказанные, без обещания совместимости.

## Отзывы и донатеры

На GitHub Pages форма готовит текст отзыва локально. Пользователь копирует его,
открывает Telegram-чат RTLC и самостоятельно отправляет сообщение. Сайт не
отправляет POST-запросы и не показывает подтверждение получения командой.
Если доступ к буферу обмена запрещён, текст можно выделить и скопировать вручную.
После модерации добавьте отзыв в `data/reviews.json` с `approved: true`.
Список донатеров хранится в `data/donors.json`. Для обоих списков предусмотрены
состояния загрузки, пустого результата и ошибки с повторной попыткой.

- Steam-плашки и мини-иконки: `assets/steam/`; файлы именуются по `id` проекта.

Для всех 27 игр локально сохранены официальные Steam header-баннеры без кадрирования и отдельные app/community-иконки. Баннеры и иконки оптимизированы в WebP и не зависят от доступности внешнего CDN при загрузке сайта.

## Deployment

GitHub Pages публикует корень ветки `main` напрямую, без сборки. Все внутренние пути относительные, поэтому сайт корректно работает как project site по адресу вида:

```text
https://USERNAME.github.io/REPOSITORY/
```

После изменения ветки `main` публикация запускается автоматически. Источник Pages настраивается как **Deploy from a branch → main → /(root)**.
